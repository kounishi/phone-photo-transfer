# iPhone 写真取り込み (phone-photo-transfer)

iPhone で選んだ写真を、同じ Wi-Fi 経由で Windows パソコンに取り込むアプリです。

パソコン側で小さな Web サーバーを動かし、iPhone の Safari から **iOS 標準の写真ピッカー**で
写真を選んでアップロードします。**iPhone 側にアプリを入れる必要はありません。**

---

## 使い方

### 1. パソコン側でアプリを起動する

```
npm install
npm start
```

起動すると自動で待受が始まり、**QR コード**と**6桁の PIN** が表示されます。

### 2. 初回だけ: ファイアウォールを許可する

初めて起動したとき、Windows Defender ファイアウォールの確認ダイアログが出ます。
**「プライベート ネットワーク」にチェックを入れて「アクセスを許可する」** を押してください。
ここで許可しないと iPhone から接続できません。

> ダイアログを閉じてしまった場合は、
> 「Windows セキュリティ」→「ファイアウォールとネットワーク保護」→
> 「ファイアウォールによるアプリの許可」から `Electron` または `iPhone Photo Transfer` を
> 探して、プライベートにチェックを入れてください。

### 3. iPhone から接続する

1. iPhone をパソコンと**同じ Wi-Fi** につなぐ
2. iPhone の**カメラアプリ**で画面の QR コードを読み取る
3. 表示されたリンクを開く（PIN は URL に含まれているので入力不要）
4. 「写真を選ぶ」→ 送りたい写真を選択 → 「パソコンに送る」

保存先は既定で `ピクチャ\PhoneTransfer\撮影日\` です。GUI から変更できます。

## 仕様

| 項目 | 内容 |
|---|---|
| 保存先 | `%USERPROFILE%\Pictures\PhoneTransfer\YYYY-MM-DD\`（変更可、日付分けはオフにもできる） |
| HEIC | **常に JPEG へ変換**して保存。画質は GUI で3段階から選択 |
| 撮影日時 | EXIF から取得し、変換後の JPEG にも書き戻す。ファイルの更新日時にも反映 |
| 位置情報・向き・機種 | 変換後も引き継ぐ |
| JPEG / PNG | 再エンコードせず、そのまま保存（劣化なし） |
| 重複 | 内容の SHA-256 で判定。同じ写真を二度送っても増えない |
| 名前の衝突 | 中身が違えば `IMG_1234 (2).jpg` のように連番 |
| 認証 | 起動ごとに変わる6桁 PIN。同じ LAN の他の端末から勝手に送られるのを防ぐ |
| 動画 | 非対応（写真のみ）。mp4 などは受信時に弾く |

### 知っておいてほしいこと

- **これは「コピー」です。** Web ページから iPhone 内の写真を削除することはできません。
  取り込んだあと不要になったら、iPhone の「写真」アプリで削除してください。
- **iOS が先に JPEG へ変換することがあります。** Safari の写真ピッカーは、多くの場合
  HEIC を JPEG に変換してからページに渡します。このアプリの HEIC 変換は、
  変換されずに HEIC のまま届いたときのための処理です。
- **HEIC → JPEG はファイルが大きくなります。** HEIC のほうが圧縮効率が高いためです。
  12MP の写真で、1.5MB の HEIC が画質「標準」で約 2.8MB の JPEG になります。
  容量が気になる場合は GUI で「容量優先」を選んでください。
- **Live Photo は静止画1枚**になります。動画部分は取得できません。
- **送信中は iPhone の画面を消さないでください。** 画面が消えると Safari が止まり、
  送信が中断します（失敗したぶんは「再送」ボタンでやり直せます）。
- 変換は 1 枚ずつ順番に行います（メモリを抑えるため）。HEIC 1 枚あたり 2〜4 秒程度かかります。

## .exe を作る

```
npm run dist
```

`dist/` に以下が出力されます。

- `iPhone Photo Transfer Setup <version>.exe` … インストーラ
- `iPhone Photo Transfer-<version>-portable.exe` … インストール不要の単体 exe

### ポータブル版について

exe を**ダブルクリックするだけ**で起動します。インストールも管理者権限も不要です。

- 起動すると `%TEMP%` の下の固定名フォルダに中身が展開されて動きます。この名前はビルド時に
  決まり、**起動のたびに変わりません。** そのためファイアウォールの許可は一度通れば
  次回以降も有効です。
- 設定（保存先・画質・接続先ネットワーク）は `%APPDATA%\phone-photo-transfer\settings.json`
  に保存されます。ポータブル版・インストーラ版・`npm start` のいずれでも**同じ設定を共有**
  します。設定を一度も変更していない間はファイル自体が作られず、既定値で動きます。
- 終了はウィンドウを閉じるだけです。展開されたファイルは `%TEMP%` に残り、次回はそれを
  再利用します。消しても次回起動時に再展開されるので、消して構いません。

コード署名をしていないため、**インターネットやネットワーク越しに配布した exe** は
初回起動時に SmartScreen の警告が出ます。**「詳細情報」→「実行」** で起動できます。
このパソコンでビルドしたものをそのまま使う場合、この警告は出ません。

## 動作確認

```
# サーバーと保存処理の通し確認（Electron なしで動く）
node scripts/selftest.js <HEIC ファイルのパス>

# 起動中のアプリの GUI が描画されているかを実測
npx electron . --remote-debugging-port=9222
node scripts/uicheck.js

# 起動中のアプリに実際に写真を送って GUI への反映まで確認
node scripts/e2e.js <PIN> <画像のパス>

# 大量送信でメモリが膨らまないこと（ストリーム処理）の確認
node scripts/loadtest.js 60
```

## つながらないときは

| 症状 | 対処 |
|---|---|
| QR を読んでもページが開かない | ファイアウォールで「プライベート ネットワーク」を許可したか確認 |
| 同上 | iPhone とパソコンが同じ Wi-Fi か確認（ゲスト用 SSID は端末間の通信が遮断されていることがあります） |
| 同上 | GUI の「接続に使うネットワーク」で別のアドレスを選ぶ |
| 「PIN が違います」 | アプリを再起動すると PIN が変わります。QR を読み直してください |
| 送信が途中で止まる | iPhone の画面が消えた可能性。「失敗した分だけ再送」を押してください |

## 構成

```
src/
  main/
    main.js       Electron 本体・ウィンドウ・IPC
    preload.js    contextBridge で renderer に API を公開
    server.js     Express + busboy、PIN 認証、iPhone 向けページの配信
    pipeline.js   受信 → HEIC 変換 → EXIF 再注入 → 保存 → 重複判定
    network.js    LAN アダプタの列挙とランク付け
    settings.js   設定の永続化
  renderer/       パソコン側の GUI
  web/            iPhone に配信するページ
scripts/          動作確認用
```

主要な依存はすべて純 JavaScript（`heic-convert` は WASM）で、ネイティブビルドは不要です。
